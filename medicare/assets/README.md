# Assets

These are tiny **placeholder** PNGs so the project builds out of the box.
Replace them before shipping:

| File                | Recommended size | Purpose                    |
| ------------------- | ---------------- | -------------------------- |
| `icon.png`          | 1024×1024        | App icon                   |
| `adaptive-icon.png` | 1024×1024        | Android adaptive foreground |
| `splash.png`        | 1284×2778        | Splash screen              |
| `favicon.png`       | 48×48            | Web favicon                |

Tip: design in Figma (medical app community templates) or generate with
`npx expo-optimize` after adding full-res source images.
